# Examples

- `cron.txt`: crontab lines (trace, daily status check, weekly list of changes).
- `pathmap.service`: a hardened systemd unit for `pathmap watch`.
- `task-scheduler.ps1`: the same on Windows with Task Scheduler.
- `traceroute-linux.txt`: a saved output; try `pathmap parse examples/traceroute-linux.txt --target 8.8.8.8`.
